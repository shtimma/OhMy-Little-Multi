# Oh My Little Multi 🌈

**Oh My Little Multi** — это образовательное Android-приложение для детей, превращающее изучение таблицы умножения в увлекательное 3D-приключение. 

## ✨ Особенности проекта

### 🎨 Дизайн и UI
- **3D-Pixel-Perfect UI**: Интерфейс вдохновлен классическими тактильными играми. Каждая кнопка имеет честный объем, тени и глянцевые блики.
- **Интерактивные маскоты**:
    - **Мудрая Сова**: Наставник, который дает подсказки и следит за правильностью ответов. Ее дизайн защищен и выполнен с использованием сложных радиальных градиентов.
    - **Дракончик**: Верный спутник, подбадривающий игрока в процессе прохождения.
- **Эффект погружения**: Плывущие облака, холмы на заднем плане и плавная анимация элементов создают живой игровой мир.

### 🧠 Методика обучения (Система Лейтнера)
В игру встроена научно обоснованная система интервальных повторений — **Алгоритм Лейтнера (5 ящиков)**:
1. Новые или сложные примеры попадают в **Box 1** и появляются часто.
2. При правильном ответе задача перемещается в следующий ящик (Box 2, 3 и т.д.).
3. При ошибке задача немедленно возвращается в **Box 1**.
4. Прогресс сохраняется в `SharedPreferences`, что позволяет эффективно выучить именно те примеры, которые вызывают трудности.

### 🎮 Игровой процесс
- **Equation Card**: Центральная карточка с примером и "3D-слотом" для выбранного ответа.
- **Answer Bank**: Отдельная панель с вариантами ответов, оформленная в виде удобного "лотка".
- **Система подсказок**: Позволяет узнать окончание числа или получить логическую наводку ценой небольшого штрафа к очкам.
- **Празднование победы**: По завершении серии из 5 вопросов игрока ждет салют из конфетти (библиотека Konfetti).

## 🛠 Технический стек
- **Язык**: Kotlin
- **Архитектура**: ViewBinding, Fragment-based navigation.
- **UI**: ConstraintLayout, Custom Vector Drawables (3D-стилизация), Material 3.
- **Анимации**: ObjectAnimator, XML-анимации (pulse, float, pop).
- **Хранение данных**: SharedPreferences (состояние системы Лейтнера).

## 🚀 Как запустить
1. Склонируйте репозиторий.
2. Откройте проект в **Android Studio Ladybug (или новее)**.
3. Запустите на эмуляторе или реальном устройстве с API 24+.
